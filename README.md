# Book Haven Bookstore Website
Book Haven is a website for a local bookstore that promotes books, magazines, journals, and office supplies. The website is designed to help customers explore available products, learn about the bookstore, and stay updated on community events.

This website was developed as part of the Sophia Learning Introduction to Web Development course as a Touchstone project. It demonstrates website design, responsive layouts, and the use of HTML, CSS, and JavaScript to create an interactive website.
